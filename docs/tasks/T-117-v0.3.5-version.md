## Goal

The release has two parts:

- **The core moves from `0.3.4` to `0.3.5`** with T-113: the generated CI cache survives a move of
  `gate.lock`.
- **`nestjs` moves from `0.3.2` to `0.3.3`** with two new rules in no preset: T-114's
  `nestjs/kind-imports` and T-115's `nestjs/typeorm-lock-owner`.

The tags are `v0.3.5` and `plugin-nestjs-v0.3.3`. The plugin interface stays `gate:plugin@0.3.0`.
Neither release needs the other: `nestjs` 0.3.3 loads in any 0.3.x core. The shape is that of
T-111.

## Scope

1. On a branch `task/T-117-v0.3.5-version` from `main`:
   - set the workspace version, and update `Cargo.lock` with `cargo update --workspace --offline`;
   - set `nestjs` to `0.3.3`;
   - every other plugin keeps its version.
2. Prove which plugins change:
   - Build the 13 `wasm32-wasip2` components at `v0.3.4` and at `main` before the bump, one lane
     job each, and compare each sha256.
   - Expect `nestjs` to change bytes from its code.
   - T-114 moved shared code into `gate-typescript`, so `typescript` and any other plugin built on
     that crate may change bytes too. The lead's decision: such a plugin keeps its version and its
     released assets, as long as its own tests are unmodified and pass.
   - Record every plugin whose bytes change, with the reason.
   - If a plugin's bytes change for any other reason, stop: the lead decides.
3. The changelogs:
   - Turn the `## Unreleased` section of `CHANGELOG.md` into `## [0.3.5]`. Turn the one in
     `plugins/nestjs/CHANGELOG.md` into `## [0.3.3]`.
   - Each entry links its merge commit on `main`: T-113 `201e623`, T-114 `f1540f5`, T-115 `250e9e7`.
   - The `nestjs` section says that both rules are in no preset, and how to turn each on. It names
     the `typescript/barrel-imports` options under which `nestjs/kind-imports` and that rule agree.
   - The core section keeps the step "run `gate sync` and commit the workflow".
   - Leave each date as "(unreleased)"; the lead dates it on merge.
   - The internal line of `plugins/typescript/CHANGELOG.md` leaves that changelog with its
     `## Unreleased` heading, so its top heading is 0.3.1 again and `release-check.sh` agrees; that
     plugin is not released. The line is kept word for word under "Unreleased changes in kept
     plugins" below, and the next `typescript` release takes its entry from there.
4. Every place that names the current core says `0.3.5`, and every pin of `nestjs` says `0.3.3`.
   Check with `scripts/release-check.sh 0.3.5`, passing `--keep` for each kept plugin. The root
   `gate.toml` moves after the release, in a task of its own.
5. No other change.
