## Goal

The core moves from `0.3.1` to `0.3.2` so that the tag `v0.3.2` equals the Cargo version the release
workflow checks. T-098 changed the wasm bytes of five plugins against `v0.3.1` (its own code and the
`regex-automata` features); they move from `0.3.0` to `0.3.1` and each gets a plugin tag. The other
eight stay at `0.3.0`, `ci` too: its only change since `v0.3.1` is the rule page
`plugins/ci/rules/concurrency.md`, which is not compiled into the component. The plugin interface
stays `gate:plugin@0.3.0`. The shape is that of the 0.3.1 release (T-097, merge `c7b40d1`).

## Scope

1. On a branch from `main` at `3f4009a`: the workspace version, and `Cargo.lock` by
   `cargo update --workspace --offline`; `cdk`, `frontend`, `ledger`, `nestjs` and `typescript` name
   `0.3.1`, every other plugin keeps `0.3.0`.
2. Proof of the list: the 13 `wasm32-wasip2` components built at the tip, each sha256 compared with
   the asset released for `v0.3.1` (the `plugin-<name>-v0.3.0` releases). If the plugins whose bytes
   change are not exactly the five, the lead decides before anything else.
3. The root `CHANGELOG.md`: a `## [0.3.2](compare link) (date)` section in the style of 0.3.1, each
   entry linked to its commit on `main`: T-098 (merge `3f4009a`), T-099 (merge `89d58cb`), T-100
   (merge `03ab4b7`). Each of the five plugins' `CHANGELOG.md` gets a `0.3.1` section that says what
   made it faster.
4. Every place that names the current core says `0.3.2`, and every pin of one of the five plugins
   says `0.3.1` (`scripts/release-check.sh 0.3.2` with `--keep` for each of the 13 plugins); a pin of
   another plugin, the plugin interface, and the root `gate.toml` (it pins released assets, so it
   moves after the release) stay.
5. No other change.

## Done when

- `scripts/release-check.sh 0.3.2 --keep <each plugin>` exits 0.
- `scripts/changelog-section.sh CHANGELOG.md 0.3.2` prints the section.
- One lane round on the pushed tip: fmt, clippy, test, deny and the release build exit 0, each
  workspace member compiled from the round's worktree; and the 13 `wasm32-wasip2` plugin components
  build. It is the first full `cargo test` round on `main` with T-098, T-099 and T-100 together. No
  tag is pushed; the lead tags.
