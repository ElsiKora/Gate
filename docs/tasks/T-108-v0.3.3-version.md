## Goal

The core moves from `0.3.2` to `0.3.3`, so the tag `v0.3.3` equals the Cargo version the release
workflow checks. T-105 changes the `ledger` plugin's code and rules, so `ledger` moves from `0.3.1`
to `0.3.2` and gets the tag `plugin-ledger-v0.3.2`. The plugin interface stays `gate:plugin@0.3.0`.
The shape is that of the 0.3.2 release (T-101).

## Scope

1. On a branch from `main`:
   - the workspace version, and `Cargo.lock` by `cargo update --workspace --offline`;
   - `ledger` names `0.3.2`;
   - `nestjs` keeps `0.3.2`, `cdk`, `frontend` and `typescript` keep `0.3.1`, and every other
     plugin keeps `0.3.0`.
2. Prove which plugins change:
   - Build the 13 `wasm32-wasip2` components at `main` before the bump, and at the `main` commit of
     the 0.3.2 release (tag `v0.3.2`, merge of T-101) or the commit `plugin-nestjs-v0.3.2` names
     for `nestjs`.
   - Both builds are on this host, one lane job each.
   - Compare each sha256.
   - If any plugin other than `ledger` changes bytes from code, not from the version bump, stop:
     the lead decides before anything else.
3. The root `CHANGELOG.md`:
   - T-105 already wrote a `## [0.3.3]` section. Complete it in the style of 0.3.2, with each entry
     linked to its merge commit on `main`.
   - The entries: T-092 (merge `80db512`; its line is in the lead's note, given in the session),
     T-104, T-105, T-106 and T-107.
   - Keep the intro paragraph on upgrading core and `ledger` together. Add the config changes a
     user must make:
     - `ledger/rule-decisions`, `ledger/root-rule-decisions`, `ledger/exception-decisions` and
       `ledger/root-exception-decisions` are one rule, `ledger/config-decisions`;
     - under `[decision-policy]`, lowering a rule that no preset names needs a decision;
     - a root project's rules no longer report a nested project's files.
   - `plugins/ledger/CHANGELOG.md` gets its `0.3.2` section (T-105 started it).
   - Dates come from `date -Iseconds` on the day of the tag; the lead sets it if it moves.
4. Version references:
   - Every place that names the current core says `0.3.3`, and every pin of `ledger` says `0.3.2`.
   - Check with `scripts/release-check.sh 0.3.3`, passing `--keep` for each plugin that keeps its
     version.
   - A pin of another plugin, the plugin interface, and the root `gate.toml` stay. The root
     `gate.toml` pins released assets, so it moves after the release, in a task of its own.
5. No other change.
