## Goal

need each other. So the core moves from `0.3.3` to `0.3.4` and `ledger` from `0.3.2` to `0.3.3`,
with the tags `v0.3.4` and `plugin-ledger-v0.3.3`. The plugin interface stays `gate:plugin@0.3.0`.
The shape is that of T-108.

1. On a branch `task/T-111-v0.3.4-version` from `main`:

   - `ledger` names `0.3.3`;
   - every other plugin keeps its version.
2. Prove which plugins change:

     job each, on this host.

3. The changelogs:
   - complete the `0.3.3`-style section T-109 wrote: `## [0.3.4]` in `CHANGELOG.md` and
     `## [0.3.3]` in `plugins/ledger/CHANGELOG.md`;

   Check with `scripts/release-check.sh 0.3.4`, with `--keep` for each kept plugin. The root
   `gate.toml` moves after the release, in a task of its own.
